# サブセットの入力

`public/assets/fonts/*.woff2` を作るときに `pyftsubset --text-file=` へ渡すファイルを置く。
**配信されない**（`public/` の外にある）。手順の全体は Tasks の SOW と README の「Web フォントを積む」にある。

| ファイル | 中身 | 出どころ |
|---|---|---|
| `charset-base-ja.txt` | 和文の漢字以外（かな・約物・全角英数・記号） | Unicode の範囲から機械生成。385字 |
| `charset-joyo.txt` | 常用漢字 2136字 | **未配置。** 下の手順で取得する |
| `charset-latin.txt` | Inter に担当させる範囲（ASCII・Latin-1・引用符・‰′″ など） | Unicode の範囲から機械生成。220字 |

## これらのファイルにコメントを書かないこと

`pyftsubset --text-file=` は**ファイルの中身を丸ごと「サブセットに含める文字」として読む**。
`#` で始まる行もコメントにならず、`#` という文字がサブセットに入る。
説明は必ずこの README に書き、データファイルには文字だけを置く。

## `charset-joyo.txt` の取得

常用漢字表（2136字）は権威ある出典から取る。手で書き起こさない。取りこぼすと豆腐になる。

取得したら1行に連結して `scripts/font-subset/charset-joyo.txt` に保存する（改行や区切りが混ざっていても
`pyftsubset` は無視するので、整形は不要）。

配置後に次を確認する。

```sh
node tests/check-glyphs.mjs
```

サイトに出ている文字が、この3ファイルの範囲に収まっているかを見る。
**常用漢字外の字を使っていればここで落ちる**（人名・地名の異体字が典型）。
落ちたら、その字を `charset-joyo.txt` に足してフォントを作り直し、ファイル名のバージョンを上げる。

## `charset-latin.txt` と `tokens.css` は必ず一致させる

`tokens.css` の `@font-face` に書く `unicode-range` と、このファイルの範囲は同じでなければならない。

- `unicode-range` にあってサブセットに無い → その文字が豆腐になる
- サブセットにあって `unicode-range` に無い → 和文書体が描く（容量の無駄）

現在の対応は次のとおり。

```
U+0020-007E   ASCII 印字可能
U+00A0-00FF   Latin-1 補助（¥ © ° × ÷）
U+2018-201F   引用符
U+2030-2044   ‰ ′ ″ ‹ › ⁄
```

`U+2014`（—）と `U+2026`（…）は**意図的に欧文側へ入れていない**。
和文の行の中で欧文書体に取られると幅と高さが浮くため、和文書体に描かせる。
この2字は `charset-base-ja.txt` が持っている。
