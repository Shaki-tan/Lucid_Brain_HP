# Docs

HP・法務文書・その他のための、**運用の資料**の置き場所。ページの構築、保守、公開文書の確認などに使う。

- **配信しない。** `public/` の外にあるので、デプロイされない。
- **git に入れる。** 作業中のメモ（`Tasks/`。git に入れない）とは違い、残しておく資料を置く。

## 置くもの

- プライバシーポリシーが事実として書いている HP の設定（[PRIVACY_SETTINGS.md](PRIVACY_SETTINGS.md)）
- 公開文書（法務文書・同意の文言等）の確認の手順
- 保守の手順のうち、SPEC に書くほどではないもの

## 置かないもの

- 秘密情報（API キー・トークン・Webhook の署名シークレット等）
- 個人情報（購入者・問い合わせをした人の情報、ログの写し等）
- 作業中のメモ・SOW・レポート（`Tasks/`）

リポジトリの公開設定によっては、ここは外から見える。上のものは置かない。

## SPEC との関係

- 仕様と決まりは `SPEC.md` に書く。
- ここの資料が決まりを持つとき（`PRIVACY_SETTINGS.md`）は、SPEC からその資料を参照する。その決まりについては、ここの資料を正とする。

## 名前の付け方（AGENTS.md 1.1）

- ディレクトリは PascalCase（`Docs/`、`Docs/Legal/` 等）。
- 常設の文書ファイルは UPPER_SNAKE_CASE（`PRIVACY_SETTINGS.md`）。
- ファイル名・ディレクトリ名は ASCII にする。
