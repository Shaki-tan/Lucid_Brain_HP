プライバシーポリシー

最終改定日: 【仮】2026年10月15日

Lucid Brain（以下「当方」といいます。）は、個人情報の保護に関する法律（以下「個人情報保護法」といいます。）その他の関係法令を守り、当方の事業において取り扱う個人情報を、次のとおり取り扱います。

第1条（適用範囲）

  1. 本ポリシーは、当方の事業において当方が取り扱う個人情報に適用します。当方の事業には、当方の Web サイト（https://lucidbrain.jp/ 配下のページをいいます。以下「本サイト」といいます。）の運営、当方の製品の販売・提供、お問い合わせへの対応、受託開発・コンサルティングその他の取引を含みます。
  2. 当方の製品で利用者が作成・保存するデータの扱いは、第4条によります。

第2条（取得する情報）

当方は、次の情報を取得します。

区分取得する情報取得の方法
製品の購入者氏名、メールアドレス、決済の記録（購入した製品、金額、日時、決済の識別番号）、購入時の同意の記録決済代行事業者（第5条）から受け取ります
お問い合わせをされた方氏名、メールアドレス、お問い合わせの内容、その他お問い合わせの中で提供された情報電子メールで受け取ります
取引先・見込み客のご担当者氏名、所属、役職、連絡先、やり取りの内容名刺、電子メール、打合せ等で受け取ります
アンケートにご回答いただいた方メールアドレス、アンケートへの回答（ご利用の目的、満足度等）アンケートのフォームで受け取ります
本サイトを閲覧された方アクセス解析の情報、障害調査のための通信の記録本サイトの閲覧に伴い取得します（第6条）

第3条（利用目的）

  1. 当方は、取得した情報を、次の目的で利用します。
    区分利用目的
    製品の購入者決済の確認、請求書の送付／製品の引渡し（ダウンロードできない場合の別の方法による提供を含みます）／返金、重大な不具合への対応／同意の内容の確認
    お問い合わせをされた方お問い合わせへの回答と、そのために必要な連絡
    取引先・見込み客のご担当者商談、見積り、契約の締結と履行、請求、連絡
    アンケートにご回答いただいた方製品・サービスの改善、ご利用の目的・満足度の把握
    本サイトを閲覧された方本サイトの運営と改善／障害の調査、不正なアクセスへの対応
  2. 当方は、製品の購入者、お問い合わせをされた方、および取引先・見込み客のご担当者の情報を、前項のほか、次の目的でも利用します。
    • 当方の製品・サービス（受託開発・コンサルティング等を含みます。）の案内・提案
    • 製品の新しい版や新しい製品のお知らせ
    • 市場調査、製品・サービスの企画
  3. 前項の案内・お知らせを電子メールで送る場合は、特定電子メールの送信の適正化等に関する法律に従い、送信者の表示と配信停止の方法を示します。配信の停止を求められた方には、以後送信しません。
  4. 当方は、法令に基づく場合を除き、前各項の目的の範囲を超えて個人情報を取り扱いません。利用目的を変更する場合は、変更後の目的を本ポリシーで公表し、法令により必要な場合は本人に通知し、または同意を得ます。

第4条（当方の製品で扱われるデータ）

  1. 当方の製品で利用者が作成・保存するデータの扱いは、製品ごとに本条に定めます。当方が利用者のデータを取得する製品を提供する場合は、取得する情報、利用目的および保存の方法を、その製品について本条に定めます。
  2. 当方の製品のうち、Pawgress（以下「本ソフトウェア」といいます。）で扱われるデータは、次のとおりです。
    1. 本ソフトウェアで作成・保存されたタスク・予定その他のデータは、利用者のパソコンに保存されます。当方は、これらのデータを取得せず、保持しません。
    2. 本ソフトウェアの AI 機能を利用すると、入力された内容その他のデータが、利用者が選んだ AI 事業者へ、利用者自身の API キーを用いて、本ソフトウェアから直接送信されます。当方はこの送信を経由せず、送信されたデータを取得しません。送信されたデータの扱いは、利用者と AI 事業者との間の契約によります。
    3. API キーは、利用者のパソコンにのみ保存され、当方には送信されません。
    4. AI 機能を除き、本ソフトウェアは外部と通信しません。
    5. 詳しくは、Pawgress 利用規約をご確認ください。

第5条（決済）

  1. 製品の代金の決済は、【Stripe の契約相手方】（以下「Stripe」といいます。）が提供する画面で行われます。購入者が決済の画面に入力したカード情報その他の情報は、Stripe が取得し、Stripe のプライバシーポリシー（【リンク】）に従って取り扱われます。
  2. 当方は、カード番号を取得しません。当方は、決済の処理と第3条の目的に必要な範囲で、購入者の氏名、メールアドレスおよび決済の記録を Stripe から受け取ります。

第6条（アクセス解析、通信の記録、Cookie）

  1. 当方は、本サイトの閲覧状況を把握するため、Cloudflare, Inc. が提供する Cloudflare Web Analytics を利用しています。この解析は Cookie を使わない方式で行われ、閲覧されたページ、参照元、ブラウザの種類等の情報が、閲覧者のブラウザから Cloudflare へ送信されます。当方は、集計された情報のみを閲覧します。
  2. 当方は、障害の調査のため、本サイトの動作の記録を【最長7日間】保存します。当方は、この記録に氏名、メールアドレスを含めません。【この記録に IP アドレスその他の情報が含まれるかを、確認結果に合わせて記載】
  3. 本サイトは、Cookie を設定しません。【Cloudflare の機能が Cookie を設定するかを、確認結果に合わせて記載】

第7条（第三者への提供）

  1. 当方は、次の場合を除き、あらかじめ本人の同意を得ないで、個人データを第三者に提供しません。
    1. 法令に基づく場合
    2. 人の生命、身体または財産の保護のために必要がある場合であって、本人の同意を得ることが困難であるとき
    3. 公衆衛生の向上または児童の健全な育成の推進のために特に必要がある場合であって、本人の同意を得ることが困難であるとき
    4. 国の機関もしくは地方公共団体またはその委託を受けた者が法令の定める事務を遂行することに対して協力する必要がある場合であって、本人の同意を得ることにより当該事務の遂行に支障を及ぼすおそれがあるとき
    5. 提供先が学術研究機関等である場合であって、提供先が当該個人データを学術研究の目的で取り扱う必要があるとき（当該個人データを取り扱う目的の一部が学術研究の目的である場合を含み、個人の権利利益を不当に侵害するおそれがある場合を除きます。）
  2. 当方が事業を承継させる場合（法人化を含みます。）、事業の承継に伴い、承継者に個人データを引き継ぐことがあります。この引継ぎは、個人情報保護法上、第三者への提供にあたりません。

第9条（安全管理措置）

当方は、個人データの漏えい、滅失または毀損を防ぐため、次の措置を講じています。

  • 組織的・人的な措置: 個人データを取り扱う者を、事業者と、事業者の指示のもとで本サイトおよび製品の開発・運用を行う者に限定し、取扱いの方法を定めています。
  • 物理的な措置: 個人データを取り扱う端末の盗難・紛失を防ぎ、端末にはパスワード等による保護を施しています。
  • 技術的な措置: 決済・配信・電子メールのサービスのアカウントに二要素認証を設定し、アクセスできる者を限定しています。本サイトの動作の記録には、氏名・メールアドレスを含めない設計としています。
  • 外的環境の把握: 第8条のとおり、個人データを取り扱う外国の制度を把握しています。

第10条（保有と削除）

  1. 当方は、個人情報を、利用目的の達成に必要な期間保有し、不要になったものは削除します。
  2. 法令により保存が義務づけられている情報（決済の記録等）は、法令が定める期間保存します。

第11条（開示等の請求）

  1. 本人は、当方が保有する本人の保有個人データについて、個人情報保護法に基づき、利用目的の通知、開示、訂正・追加・削除、利用の停止・消去、第三者への提供の停止、および第三者提供記録の開示を請求できます。
  2. 請求は、第14条の窓口へ電子メールでご連絡ください。
  3. 当方は、請求をされた方が本人であることを確認したうえで対応します。確認は、製品の購入者については決済に使われたメールアドレスからのご連絡と決済の日時等の照合により、その他の方についてはご連絡いただいたメールアドレスとやり取りの内容の照合等により行います。
  4. 代理人による請求の場合は、委任状その他代理権を確認できる書類と、代理人ご本人を確認できる書類をご提出いただきます。未成年者または成年被後見人の法定代理人による請求の場合は、法定代理人であることを確認できる書類をご提出いただきます。
  5. 請求の手数料は、無料とします。

第12条（対象地域と言語）

  1. 当方の製品の販売は、日本国内に居住する方を対象としています。
  2. 本ポリシーは日本語を正文とします。英語その他の言語による版は参考のための要約であり、内容に違いがある場合は日本語の版が優先します。

第13条（本ポリシーの変更）

  1. 当方は、法令の改正、取扱いの変更その他の必要に応じて、本ポリシーを変更することがあります。
  2. 変更後の本ポリシーは、本サイトに掲載した時から効力を生じます。利用目的の変更その他法令により本人への通知または同意が必要な変更は、法令に従い通知し、または同意を得ます。
