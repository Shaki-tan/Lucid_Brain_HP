プライバシーポリシー

最終改定日: 2026年10月17日

Lucid Brain（以下「当方」といいます。）は、個人情報の保護に関する法律（以下「個人情報保護法」といいます。）その他の関係法令を守り、当方の事業において取り扱う個人情報を、次のとおり取り扱います。

第1条（適用範囲）

  1. 本ポリシーは、当方の事業において当方が取り扱う個人情報に適用します。当方の事業には、当方の Web サイト（https://lucidbrain.jp/ 配下のページをいいます。以下「本サイト」といいます。）の運営、当方の製品・サービスの販売・提供、お問い合わせへの対応、受託開発・コンサルティングその他の取引を含みます。
  2. 当方の製品・サービスで扱われるデータの扱いは、第4条、または当方が製品・サービスごとに示す説明（本ポリシーの別表、製品・サービスの中の表示等をいいます。以下「製品ごとの説明」といいます。）によります。
  3. 本ポリシーで用いる「個人情報」「個人データ」「保有個人データ」「個人関連情報」「仮名加工情報」「匿名加工情報」その他の用語は、個人情報保護法の定めによります。

  1. 当方は、次の情報を取得します。
    区分取得する情報取得の方法
    製品の購入者氏名、メールアドレスその他決済の画面で入力された情報（カード番号を除きます。）、決済の記録（購入した製品、金額、日時、決済の識別番号）、購入時の同意の記録決済代行事業者（第5条）から受け取ります

    アンケートにご回答いただいた方メールアドレス、アンケートへの回答アンケートのフォームで受け取ります

    • アカウントの情報（氏名、表示名、メールアドレス、認証に必要な情報等）
    • 利用者が製品・サービスに入力し、または保存した情報（文章、画像、ファイル、設定等）
    • 製品・サービスの利用の記録（利用の日時、操作の記録、エラーの記録等）
    • 端末と通信の情報（端末・OS・ソフトウェアの種類と版、IP アドレス、Cookie その他の識別子等）
    • 契約・購入の状況、お問い合わせへの対応の記録

  4. 当方は、法令に基づく場合を除き、前各項の目的の範囲を超えて個人情報を取り扱いません。利用目的を変更する場合は、変更後の目的を本ポリシーで公表し、法令により必要な場合は本人に通知し、または同意を得ます。

第4条（当方の製品・サービスで扱われるデータ）

  1. 当方の製品・サービスで扱われるデータの扱いは、製品・サービスごとに、本条または製品ごとの説明で示します。
  2. 当方の製品のうち、Pawgress（以下「本ソフトウェア」といいます。）で扱われるデータと、本ソフトウェアが行う通信は、次の表のとおりです。当方は、本ソフトウェアで扱われるデータを取得せず、保持しません。
    対象扱い
    本ソフトウェアで作成・保存したデータ（タスク、予定、チャット、添付したファイル等）利用者のパソコンにのみ保存されます。本ソフトウェアをアンインストールすると、パソコン上のこれらのデータは削除されます。
    AI 機能で送信されるデータ（入力した内容、添付したファイル、タスク・予定等）利用者が選んだ AI 事業者（利用者が接続先として指定したサーバーを含みます。）へ、利用者自身の API キーを用いて、本ソフトウェアから直接送信されます。当方はこの送信を経由しません。送信されたデータの扱いは、利用者と AI 事業者との間の契約によります。
    AI 機能による Web ページの読み込みAI が Web ページの読み込みを求めた場合、本ソフトウェアは、利用者のパソコンから、そのページのサイトへ直接接続します。そのサイトには、IP アドレス、通信に使うソフトウェアの種類（User-Agent）等の情報が送られます。また、読み込んだページに含まれるプログラム（アクセス解析を含みます。）が実行され、そのサイトの Cookie 等が利用者のパソコンに保存されることがあります。当方はこの接続を経由しません。
    リンクを開くときの接続の確認利用者がタスク、予定またはチャットに含まれるリンクを開くとき、本ソフトウェアは、リンク先を開けるかを確かめるため、リンク先（短縮 URL の場合は、その転送先を含みます。）に接続します。リンク先には、IP アドレス、通信に使うソフトウェアの種類（User-Agent）等の情報と、その URL が送られます。
    API キー利用者のパソコンにのみ保存され、当方には送信されません。Windows の暗号化の機能を使える環境では、暗号化して保存されます。
    その他の通信上記の場合を除き、本ソフトウェアは外部と通信しません。
  3. 本ソフトウェアのデータの扱いの詳細は、Pawgress 利用規約をご確認ください。

第5条（決済）

  1. 製品の代金の決済は、【Stripe の契約相手方】（以下「Stripe」といいます。）が提供する画面で行われます。購入者が決済の画面に入力したカード情報その他の情報は、Stripe が取得し、Stripe のプライバシーポリシー（https://stripe.com/jp/privacy）に従って取り扱われます。
  2. 当方は、カード番号を取得しません。当方は、決済の処理と第3条の目的に必要な範囲で、購入者が決済の画面に入力した情報（カード番号を除きます。）および決済の記録を Stripe から受け取ります。

第6条（Cookie、アクセス解析、通信の記録）

  1. 当方は、本サイトおよび当方の製品・サービスにおいて、Cookie、アクセス解析のツールその他の技術を用いて、閲覧・利用に関する情報を取得し、または外部の事業者へ送信させることがあります。この場合は、送信される情報、送信先および利用目的を、本条または製品ごとの説明で示します。
  2. 本サイトでは、次のとおりです。
    1. 当方は、本サイトの閲覧状況を把握するため、Cloudflare, Inc. が提供する Cloudflare Web Analytics を利用しています。この解析は Cookie を使わない方式で行われ、閲覧されたページ、参照元、ブラウザの種類等の情報が、閲覧者のブラウザから Cloudflare へ送信されます。当方は、集計された情報のみを閲覧します。
    2. 当方は、障害の調査のため、本サイトの動作の記録を最長7日間保存します。当方は、この記録に氏名、メールアドレスおよび IP アドレスを含めません。
    3. 本サイト自身は Cookie を設定しません。ただし、不正なアクセスへの対策等のため、配信に利用している Cloudflare の機能が Cookie を設定することがあります。

第7条（第三者への提供と、取扱いの委託）

  1. 当方は、法令に基づく場合その他個人情報保護法により認められる場合を除き、あらかじめ本人の同意を得ないで、個人データを第三者に提供しません。
  2. 当方が事業を承継させる場合（法人化を含みます。）、事業の承継に伴い、承継者に個人データを引き継ぐことがあります。この引継ぎは、個人情報保護法上、第三者への提供にあたりません。
  3. 当方は、利用目的の達成に必要な範囲で、個人データの取扱いの全部または一部を外部の事業者に委託することがあります。この場合、当方は、委託先に対し、個人データの安全管理のために必要な監督を行います。

第9条（安全管理措置）

当方は、個人データの漏えい、滅失または毀損を防ぐため、次の措置を講じています。

  • 組織的・人的な措置: 個人データを取り扱う者を、事業者と、事業者の指示のもとで本サイトおよび製品の開発・運用を行う者に限定し、取扱いの方法を定めています。
  • 物理的な措置: 個人データを取り扱う端末の盗難・紛失を防ぎ、端末にはパスワード等による保護を施しています。
  • 技術的な措置: 決済・配信・電子メールのサービスのアカウントに二要素認証を設定し、アクセスできる者を限定しています。本サイトの動作の記録には、氏名・メールアドレス・IP アドレスを含めない設計としています。
  • 外的環境の把握: 第8条のとおり、個人データを取り扱う外国の制度を把握しています。

第10条（保有と削除）

  1. 当方は、個人情報を、利用目的の達成に必要な期間保有し、不要になったものは削除します。
  2. 法令により保存が義務づけられている情報（決済の記録等）は、法令が定める期間保存します。

第11条（開示等の請求）

  1. 本人は、当方が保有する本人の保有個人データについて、個人情報保護法に基づき、利用目的の通知、開示、訂正・追加・削除、利用の停止・消去、第三者への提供の停止、および第三者提供記録の開示を請求できます。
  2. 請求は、第14条の窓口へ電子メールでご連絡ください。請求の方法、本人であることの確認の方法（代理人による請求の場合の確認を含みます。）その他の手続は、請求を受けた際にご案内します。
  3. 請求の手数料は、無料とします。

第12条（対象地域と言語）

  1. 当方の製品の販売は、日本国内に居住する方を対象としています。
  2. 本ポリシーは日本語を正文とします。英語その他の言語による版は参考のための要約であり、内容に違いがある場合は日本語の版が優先します。

第13条（本ポリシーの変更）

  1. 当方は、法令の改正、取扱いの変更その他の必要に応じて、本ポリシーを変更することがあります。
  2. 変更後の本ポリシーは、本サイトに掲載した時から効力を生じます。利用目的の変更その他法令により本人への通知または同意が必要な変更は、法令に従い通知し、または同意を得ます。
