Pawgress 利用規約

最終改定日: 2026年10月17日

Lucid Brain（以下「当方」といいます。）は、当方が提供するソフトウェア「Pawgress」の利用条件を、この Pawgress 利用規約（以下「本規約」といいます。）で定めます。

第1章　総則

第1条（適用範囲）

  1. 本規約は、本ソフトウェアの有償版および無料版の利用に適用します。
  2. 第3章（購入と引渡し）、第4章（重大な不具合と返金）その他「有償版」について定める規定は、有償版にのみ適用します。

第2条（定義）

本規約で使う用語の意味は、次のとおりとします。

  1. 本ソフトウェア: 当方が提供する Windows 用のタスク・予定管理ソフトウェア「Pawgress」をいいます。有償版と無料版、そのインストーラーおよび付属の文書を含みます。
  2. 有償版: 代金を支払って購入する本ソフトウェアをいいます。
  3. 無料版: 当方が無償で提供する本ソフトウェアをいいます。登録できるタスク・予定の件数に制限があります。
  4. 版: 当方が公開する本ソフトウェアの各バージョンをいいます。バージョン番号（例: 1.1.0）の3つの数字がすべて同じものを同じ版とし、1つでも異なるものは別の版とします。
  5. 購入者: 有償版を購入した者をいいます。法人その他の団体のために購入された場合は、第4条第3項のとおりその法人その他の団体をいいます。
  6. 利用者: 本ソフトウェアを利用する者をいいます。購入者、第4条の利用チームに属する者、および無料版を利用する者を含みます。
  7. ダウンロードページ: 有償版の決済の完了後に表示され、有償版をダウンロードできるページをいいます。
  8. 決済の完了: 有償版の代金の決済が、決済代行事業者（Stripe）において完了したことをいいます。
  9. 動作環境: 特定商取引法に基づく表記その他本サイトにおいて当方が示す、本ソフトウェアの動作に必要な OS その他の条件をいいます。
  10. 操作説明書: 当方が本サイトで PDF の形式で提供する、本ソフトウェアのインストール、無料版から有償版への移行、操作およびアンインストールの説明をいいます。
  11. 利用者データ: 利用者が本ソフトウェアで作成・保存したタスク、予定、チャット、設定、添付したファイルその他のデータをいいます。
  12. AI 機能: 本ソフトウェアのうち、利用者が用意した API キーを用いて、利用者が選んだ AI 事業者のサービスにデータを送信し、処理を受ける機能をいいます。
  13. AI 事業者: 利用者が AI 機能で利用する AI サービスの提供者をいいます。利用者が自ら用意し、または接続先として指定したサーバー（OpenAI 互換の環境を含みます。）を含みます。
  14. API キー: AI 事業者のサービスを利用するために、利用者が AI 事業者から取得する認証情報をいいます。
  15. 本サービス: 本ソフトウェアと、これに関して当方が提供するサービス（ダウンロードページによる提供を含みます。）をいいます。
  16. 本サイト: 当方が運営する Web サイト（https://lucidbrain.jp/ 配下のページ）をいいます。
  17. 外部サービス: 本サービスとともに利用される、第三者が提供するサービス（決済代行事業者のサービス、AI 事業者のサービスその他のサービスを含みます。）をいいます。

第3条（本規約への同意と契約の成立）

  1. 有償版を購入する者は、購入の前に当方が表示する確認画面で、本規約に同意するものとします。当方と購入者との間の、本規約を内容とする契約は、決済の完了の時に成立します。
  2. 無料版を利用する者は、ダウンロードの前に当方が表示する画面で、本規約に同意するものとします。当方と無料版の利用者との間の、本規約を内容とする契約は、この同意の時に成立します。
  3. 本規約に同意しない者は、本ソフトウェアをダウンロードし、または利用することはできません。

第4条（利用の許諾）

  3. 有償版が法人その他の団体のために購入された場合（購入手続を行った者が代金を立て替えた場合を含みます。）は、その法人その他の団体を購入者とします。購入者は、購入手続を行った者が直接管理する1つのチーム（以下「利用チーム」といいます。）に属する者に限り、有償版を利用させることができます。この場合、購入者は、利用チームに属する者に本規約を守らせるものとし、その者の行為について責任を負います。

  6. 利用チームに属さなくなった者（購入手続を行った者を含みます。）は、有償版の利用を終了するものとし、その後に属し、または管理する別のチームに有償版を利用させることはできません。
  7. 無料版は、第3条第2項により本規約に同意した者が利用できます。

第5条（禁止事項）

  1. 利用者は、第23条に定める行為のほか、次の行為をしてはなりません。
    1. 本ソフトウェア（インストーラーを含み、有償版・無料版を問いません。）を、有償・無償を問わず、前条により利用が認められる者以外の者に配布し、譲渡し、貸与し、公開し、または共有すること

  2. 本サイトにある本ソフトウェアの公式のダウンロードページへのリンクを掲載して、本ソフトウェアを紹介することは、前項第1号の行為にあたりません。

第3章　購入と引渡し（有償版）

第6条（販売価格と支払）

  1. 有償版の販売価格、支払方法および支払時期は、特定商取引法に基づく表記および購入の前に当方が表示する確認画面に示すとおりとします。
  2. 有償版の代金の支払は、決済代行事業者（Stripe）が提供する画面で、クレジットカードにより行います。

第7条（引渡し）

  1. 当方は、決済の完了後、有償版をダウンロードページでダウンロードできる状態に置くことにより、有償版を購入者に引き渡します。
  2. ダウンロードページから有償版をダウンロードできる期間（以下「ダウンロード期間」といいます。）は、決済の完了の時から72時間とします。
  3. 購入者は、ダウンロードしたインストーラーを自ら保管するものとします。ダウンロード期間内にダウンロードを行わなかった場合、およびダウンロード期間の経過後に、インストーラーの紛失、新しい端末への導入その他の理由で有償版を再びダウンロードする場合は、改めて購入する必要があります。
  4. 購入者の通信環境、セキュリティソフトの設定その他購入者側の事情によりダウンロード期間内にダウンロードできなかった場合は、決済の完了から48時間以内に、第12条の窓口にお申し出ください。当方は、決済の事実を確認したうえで、別の方法により有償版を提供します。この場合は、返金の理由になりません。

第8条（提供する版）

  1. 有償版の購入により提供する版は、購入者がダウンロードした時点の版とします。
  2. その後に当方が公開する版（不具合を修正した版を含みます。）を利用するには、別途購入する必要があります。ただし、第10条により重大な不具合を修正した版を提供する場合を除きます。
  3. 当方は、新しい版を公開する義務を負いません。

第4章　重大な不具合と返金（有償版）

第9条（重大な不具合）

  1. 本規約において「重大な不具合」とは、動作環境を満たす端末で、購入した版の有償版を操作説明書に従って利用した場合に、次のいずれかが生じることをいいます。
    1. インストールできない、または起動しない
    2. 有償版をインストールしても、無料版の件数の制限が解除されない
    3. 本ソフトウェアに保存した利用者データが消える、または壊れる（第13条に定める削除を除きます。）
    4. タスクまたは予定の作成、編集、保存または表示ができない
  2. 次のものは、重大な不具合にあたりません。
    1. 表示の乱れ、文言の誤りその他、前項各号に至らないもの
    2. 動作環境を満たさない端末で生じるもの
    3. 購入後に行われた OS その他のソフトウェアの更新、または外部サービスの変更や障害によって生じるもの
    4. AI 機能による出力の内容
    5. 無料版をアンインストールしてから有償版をインストールしたこと、その他操作説明書と異なる操作によって生じた利用者データの消失
    6. 利用者による本ソフトウェアの改変、利用者の端末の故障、ファイルの削除その他、本ソフトウェアの外の原因によって生じるもの
    7. 無料版で生じるもの
    8. 本ソフトウェアのダウンロード、インストールまたは起動の際に、Windows その他のソフトウェアのセキュリティの機能（Microsoft Defender SmartScreen 等）が警告を表示すること

第10条（重大な不具合への対応）

  1. 購入者は、有償版に重大な不具合があるときは、決済の完了の日から8日以内に、第12条の窓口に申し出ることができます。
  2. 申出の際は、決済に使ったメールアドレス、決済の日時、利用している版、端末の OS とそのバージョン、症状および再現の手順をお知らせください。当方は、不具合の確認に必要な範囲で、追加の情報の提供をお願いすることがあります。
  3. 当方は、有償版に重大な不具合があるときは、その不具合を修正した版を無償で提供します。相当の期間内に修正した版を提供できないときは、代金を返金します。

第11条（返金）

  1. 有償版は、その性質上、決済の完了後は、購入者の都合による返品・返金をお受けしません。
  2. 当方は、次の場合に限り、有償版の代金を返金します。
    1. 重複して決済された場合（同じ購入者が、先の決済の完了から72時間以内に、有償版を重ねて決済した場合をいいます。）
    2. 当方の責めに帰すべき事由により、有償版をダウンロードできる状態に置くことができず、第7条第4項の別の方法によっても提供できない場合
    3. 前条第3項により返金する場合
    4. 法令により返金が必要な場合
  3. 前項第1号の返金の申出は、後の決済の完了から48時間以内に、第12条の窓口に行うものとします。
  4. 返金は、購入時に利用された決済の方法を通じて行います。返金が利用者の口座等に反映される時期は、カード会社等によります。
  5. 返金をした場合、その購入に係る有償版の利用の許諾は終了します。購入者は、有償版の利用をやめ、利用チームに属する者を含めて、有償版を端末から削除するものとします。

第12条（申出の窓口と手続）

  1. 第7条第4項、第10条および前条の申出は、電子メール（info@example.com）で受け付けます。
  2. 申出の際は、決済の事実の確認のため、決済に使ったメールアドレスと、決済の日時（または決済代行事業者から届いた請求書・領収書の番号）をお知らせください。
  3. 当方は、決済に使ったメールアドレス以外のメールアドレスからの申出には、原則として応じません。

第5章　利用者データと AI 機能

第13条（利用者データ）

  1. 利用者データは、利用者の端末に保存されます。当方は、利用者データを取得せず、保持しません。
  2. 利用者が本ソフトウェアに添付したファイルは、本ソフトウェアの保存領域に複製して保存されます。元のファイルは変更されません。
  3. 本ソフトウェアは、タスク、予定およびチャットを、利用者が設定した保持期間を過ぎたときに自動で削除する機能を備えています。キャンセルした予定は、保持期間にかかわらず削除の対象になります。初期設定では、この機能は有効になっており、削除の前に、本ソフトウェアの起動の際に確認が表示されます。自動で削除するかどうか、保持期間および確認の表示は、利用者が設定できます。保持期間の初期値その他の詳細は、操作説明書に示します。
  4. 本ソフトウェア（有償版・無料版）をアンインストールすると、利用者データ（タスク、予定、チャット、添付したファイル、変更の記録その他のデータ）は削除されます。このとき、Windows の自動起動の登録と、インストールの際に保存されたインストーラーの控えも削除されます。
  5. 無料版から有償版に移行するときは、無料版をアンインストールせずに、操作説明書に従い、有償版のインストーラーをそのまま実行してください（上書きインストール）。上書きインストールでは、利用者データは削除されません。
  6. 利用者は、自らの責任で利用者データのバックアップを行うものとします。
  7. 利用者データに関する権利は、利用者に留保されます。

第14条（AI 機能）

  1. AI 機能を利用するには、利用者が自ら AI 事業者から API キーを取得し、本ソフトウェアに設定する必要があります。API キーの管理と、AI 事業者に支払う利用料金は、利用者の責任と負担とします。
  2. AI 事業者のサービスの利用には、利用者と AI 事業者との間の契約（AI 事業者の利用規約等）が適用されます。
  3. AI 機能を利用すると、入力された内容その他のデータが、本ソフトウェアから AI 事業者へ直接送信されます。当方はこの送信を経由せず、送信されたデータを取得しません。送信されたデータの扱いは、利用者と AI 事業者との間の契約によります。
  4. AI 機能の利用中に、AI が Web ページの読み込みを求めた場合、本ソフトウェアは、利用者の端末から、そのページのサイトへ直接接続します。当方はこの接続を経由しません。読み込んだ Web ページの内容と、そのサイトへの接続により送られる情報の扱いは、そのサイトの運営者によります。
  5. API キーは、利用者の端末にのみ保存されます。
  6. 当方は、AI 機能による出力の正確性、完全性および有用性を保証しません。利用者は、出力の内容を自ら確認したうえで利用するものとします。
  7. 利用者が自ら用意し、または接続先として指定したサーバーは、動作の確認の対象外です。
  8. AI 事業者のサービスの変更、停止または障害により、AI 機能の全部または一部を利用できなくなることがあります。
